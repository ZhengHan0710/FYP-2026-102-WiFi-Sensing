# MATLAB CSI 幅值热力图与参考数据比较

两个 .m 文件放在同一个文件夹，MATLAB 打开 run_compare.m 并点击运行。代码面向 MATLAB R2020b 及以后版本，不需要 Signal Processing Toolbox 或 Statistics Toolbox。当前已在 MATLAB R2025b 读取了全部三组实测数据与七个参考文件。

run_compare.m 已填入用户实测目录及微信参考压缩包路径。如文件移到其他电脑，请修改 userDir 和 referenceZip；路径不存在时会弹出文件选择窗口。不会修改源 CSV。输出在脚本旁边的 results 文件夹。

## 输出

- 01_heatmap.png 至 03_heatmap.png：三组实测数据，每张包含幅值和相对变化两个面板。
- 04_heatmap.png 至 10_heatmap.png：参考数据各文件的同类图。
- comparison_amplitude.png：十份数据的幅值总览，全部使用同一色标。
- comparison_relative.png：十份数据相对自身窗口中位数的变化总览，全部使用同一色标。
- .fig：MATLAB 可编辑图形。
- summary.csv：实际帧数、采样率、异常行、缺失时间分箱、信道、带宽和波动系数。
- processed_csi.mat：处理后的幅值、分箱矩阵、基准幅值与统计结果。
- plot_settings.json：可审查的绘图设置。

## 算法

1. 安全使用 jsondecode 解析 data 数组，不使用 eval。
2. 根据每对虚部、实部计算幅值 sqrt(Im^2+Re^2)。104 个整数形成 52 个复数幅值。
3. 以 local_timestamp 微秒接收时间戳为首选时间轴，处理 32 位回绕，拒绝设备时间重置；缺失时退回电脑时间字段。
4. 每个文件取开始的 60 秒。参考文件更长，但当前对比不会取不同长度窗口。
5. 每 0.1 秒内使用幅值中位数聚合。不是以相同帧数截取，避免约 20 Hz 与约 100 Hz 的速率差异造成时间轴错误。
6. 缺失分箱保留 NaN，图中呈浅灰，不插值或补零。相对图中的白色表示约零变化，与浅灰缺失区不同。
7. 相对变化 = 100 × (分箱幅值 / 该复数位置在本文件窗口的原始帧幅值中位数 - 1)。零中位数的位置保留 NaN。该定义用于比较自身波动，不是相对无人机基线的检测分数，也不是 z-score。
8. 幅值图与相对图分别统一色标。色标上界依据所有展示矩阵的 99 分位数；超出的极端值饱和显示，但原始矩阵不截断，保存在 .mat。不以各图独立自动色标制造视觉差异。
9. len 不同的帧按展示窗口的主长度保留，并报告被排除数量；first_word_invalid=1 时保守屏蔽前两个复数。本次实际数据均为 104 长度且标记为 0。

## 怎么读图

横轴是接收时间戳相对文件第一帧的秒数。纵轴是文件内的复数存储位置编号 1..52，不标称参考数据对应的具体子载波频率，因为原始参考采集及选取代码未知。

幅值图颜色显示接收系数的大小（驱动任意单位，不是 dBm）。横向平稳条带表示该位置的幅值在时间上相对稳定；竖向变化代表多位置同时变化，也可能由增益、干扰、设备位置或人员移动引起。

相对图蓝色表示低于自身中位数，橙色表示高于自身中位数。对比的是各自时间波动，不能据此判定无人机或推断标签含义。

## 本次来源差异

实测三组为 LLTF 52 对、20 MHz、信道 1，约 20 帧/秒；参考文件为 104 个整数、cwb=1（40 MHz）、信道 11，约 96..99 帧/秒，LTF 类型与子载波顺序未知。三组实测 RSSI 中位数约 -36、-36、-34 dBm，参考窗口约 -48 dBm。因此绝对幅值、各位置的频域形状及波动均受不一致条件影响。统一窗口、分箱及色标并不能消除这些差异。图是描述性比较，不是无人机识别验证，也不能用来直接确定报警阈值。

原参考 zyn 文件夹的实际标签为 wyt；图名沿用文件夹以方便查找，真实标签也保存在处理结果 labels 字段。未把参考数据认定为无人机样本。

## 可调整参数

run_compare.m 末尾：

```matlab
results = csi_heatmaps(userFiles, referenceZip, outputDir, 60, 0.1);
```

60 为展示窗口秒数，0.1 为分箱秒数。窗口必须是分箱的整数倍。扩大窗口可能导致较短实测文件的末段出现缺失灰色区；减小分箱会出现更多空箱，不能提升原始采样率。
