# 第九周算法工作总结

## 本周目标

根据上次汇报建议，本周不再只依赖两个手工统计特征，而是完成以下工作：

1. 核查项目数据的真实采样间隔；
2. 选择带论文、官方代码和基准结果的权威公开数据集；
3. 先在公开数据上验证 CNN 流程；
4. 再将 CNN 接入小组实采数据，并与已有基线形成对照。

## 已完成工作

### 1. 核查采样间隔

检查 `Stop`、`Person` 和 `person_stop` 共 9 个 CSV 的 ESP32
`local_timestamp`。各次采集的中位帧间隔均约为 **50 ms**，即约 20 帧/秒。
因此 64 帧窗口覆盖约 3.2 秒。

50 ms 不是“动作只持续 50 ms”，而是每隔 50 ms 记录一次 CSI。一个动作由连续多个采样点共同描述。

### 2. 建立 SenseFi / UT-HAR 公开基准

选择 SenseFi 官方基准中的 UT-HAR 数据集。该基准同时提供公开数据、固定划分、CNN-5
等多种模型和论文结果，适合检查本地实现是否合理。

SenseFi CNN-5 兼容运行 25 轮后：

- 测试准确率：**95.18%**；
- 宏平均召回率：**93.44%**；
- 论文报告 CNN-5 准确率：97.61%。

该结果说明公开数据读取、CNN 输入组织和训练流程基本正确，但因为没有执行论文的完整
200 轮设置，不能称为完整复现。

### 3. 将 CNN 接入项目实采数据

项目 CNN 不再把一个窗口压缩成两个数字，而是输入完整的 `64 × 52` CSI 幅度图：

- 64 行表示连续时间帧；
- 52 列表示 CSI 位置；
- `person_moving` 为运动类；
- `empty` 和 `person_stationary` 为非运动类。

为减少静态环境指纹，每个窗口先按 CSI 位置减去时间均值。数据按完整采集记录划分，
不会把同一条记录的重叠窗口同时放进训练和测试。

轮流将第 1、2、3 次采集作为测试集时，三折准确率和宏平均召回率均为 100%。固定第 3
次采集为测试集、训练 30 轮时，5 个随机种子也均达到 100%。

在第 1、2 次训练、第 3 次测试的相同划分下，单特征阈值、双特征逻辑回归和 CNN 的
准确率分别为 76.65%、89.22% 和 100.00%。这说明保留完整时间—CSI位置结构，比先把
窗口压缩为一两个统计数字更适合当前数据。

### 4. 检查 CNN 到底学到了什么

额外进行了两个诊断实验：

- 打乱窗口中的帧顺序后仍能正确分类；
- 删除所有时间波动后，准确率下降到约 57.49%。

说明模型主要利用“窗口内波动强弱及其在 CSI 位置上的分布”，而不是严格的动作顺序。

## 当前结论与限制

目前可以确认：在同一房间、同一设备布置和相近时间的采集条件下，运动场景与无人/静止
场景的 CSI 波动具有明显差异，CNN 可以稳定分离。

目前不能声称模型已经具有通用的 100% 识别率。现有三次采集属于相同实验条件，下一步
必须增加跨日期、跨位置或跨房间测试，排除模型利用环境和采集批次特征的可能。

## 下一步

1. 保持设备、信道和标签规则一致，在不同日期重新采集三类数据；
2. 增加不同人体位置和运动路线；
3. 使用旧批次训练、新批次测试，形成真正的跨批次评估；
4. 在同一测试集比较双特征逻辑回归与 CNN 的准确率、宏平均召回率和混淆矩阵；
5. 数据量增加后，再考虑相位校准及更细的人体动作分类。
