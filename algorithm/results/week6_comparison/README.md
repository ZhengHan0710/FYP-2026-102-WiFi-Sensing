# 第六周：类别不均衡方法对比

两组实验使用相同的数据划分、BiLSTM、幅度和相位特征、64 帧窗口及 10 轮训练；只改变类别不均衡处理方式。

| 方法 | 三个种子的测试准确率 | 平均准确率 | 平均宏召回率 |
|---|---:|---:|---:|
| 均衡抽样 | 24.96%, 46.06%, 40.86% | 37.30% ± 8.98% | 15.11% |
| 加权损失 | 46.06%, 46.66%, 18.72% | 37.15% ± 13.03% | 12.61% |

## 结论

- 两种方法在不同随机种子下波动都很明显，说明当前训练仍不稳定。
- 加权损失在多数运行中仍集中预测 walking，不能只依据表面准确率判断效果。
- 均衡抽样的平均宏召回率更高，能稍微改善少数类，但仍有类别召回率为 0。
- 下一步应优先检查数据划分、类别数量和跨房间分布差异，再考虑增加模型复杂度。
