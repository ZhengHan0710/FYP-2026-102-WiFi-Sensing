# Week 9: SenseFi 公开基准与项目数据 CNN 基线

## 1. 权威公开基准

- 论文：[SenseFi: A Library and Benchmark on Deep-Learning-Empowered WiFi Human Sensing](https://arxiv.org/html/2207.07859v3)
- 官方代码：[WiFi-CSI-Sensing-Benchmark](https://github.com/xyanchen/WiFi-CSI-Sensing-Benchmark)
- 数据集：UT-HAR，7 类人体活动
- 模型：SenseFi CNN-5 兼容实现
- 输入：`1 × 250 × 90`
- 训练/测试：3977 个训练样本；996 个官方评估样本

本地 CPU 训练 25 轮结果：

| 指标 | 结果 |
| --- | ---: |
| 测试准确率 | 95.18% |
| 宏平均召回率 | 93.44% |
| SenseFi 论文 CNN-5 准确率 | 97.61% |

该结果用于确认公开数据读取、CNN 输入和训练流程基本正确。由于论文正式设置为
200 轮，本结果称为兼容性验证，不称为完整复现。

## 2. 项目实采数据 CNN

任务为 `person_moving` 与 `nonmoving` 二分类，其中 `empty` 和
`person_stationary` 都属于 `nonmoving`。

- 每帧：52 个 CSI 幅度位置
- 每个窗口：64 帧，约 3.2 秒
- 模型输入：`1 × 64 × 52`
- 预处理：每个窗口按 CSI 位置减去时间均值，再使用训练记录统计量标准化
- 损失：类别加权交叉熵
- 划分：按完整采集记录留一，禁止一条记录的重叠窗口同时进入训练和测试
- 训练：30 轮，随机种子 42

按采集记录留一的结果：

| 测试记录 | 测试窗口 | 准确率 | 宏平均召回率 |
| ---: | ---: | ---: | ---: |
| 1 | 183 | 100.00% | 100.00% |
| 2 | 176 | 100.00% | 100.00% |
| 3 | 167 | 100.00% | 100.00% |

固定第 3 次采集为测试集时，5 个随机种子训练 30 轮均达到 100%。

在完全相同的“第 1、2 次训练，第 3 次测试”划分下，与前期方法比较：

| 方法 | 输入 | 准确率 | 宏平均召回率 |
| --- | --- | ---: | ---: |
| 单特征阈值 | 归一化相邻帧变化 | 76.65% | 79.14% |
| 逻辑回归 | 时间标准差 + 归一化相邻帧变化 | 89.22% | 89.71% |
| 小型 CNN | 去均值后的 `64 × 52` 幅度图 | **100.00%** | **100.00%** |

该对比表明，在当前采集批次中，保留完整时间—CSI位置结构比先压缩成一两个统计量更有效。

## 3. 诊断实验与结果边界

对第 3 次测试记录进行诊断：

- 打乱 64 帧的时间顺序：准确率仍为 100%；
- 删除所有时间波动，只重复窗口时间均值：准确率降至 57.49%。

这说明模型依赖窗口内的 CSI 波动分布，但目前不依赖严格的动作先后顺序。当前结果只证明：
在同一房间、同一设备布置和相近采集时间内，运动与非运动高度可分。它不能证明跨日期、
跨位置或跨房间仍为 100%。

## 4. 复现项目 CNN

在项目根目录执行：

```bash
python algorithm/motion_cnn_baseline.py \
  --data-root data \
  --output /tmp/fyp_motion_cnn \
  --input-mode centered \
  --test-recording 3 \
  --epochs 30 \
  --seed 42
```

三个输入模式：

- `amplitude`：保留完整幅度，包括静态环境指纹；
- `centered`：减去每个窗口的时间均值，作为当前正式设置；
- `difference`：使用相邻帧幅度差。
